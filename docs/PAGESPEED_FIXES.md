# إصلاحات فحص PageSpeed — 14 نوفمبر 2026

## المدخلات

أربع صور لفحص الجوال: FCP 0.9s وLCP 1.8s وTBT 30ms وCLS 0 وSpeed Index 3.4s،
مع تحذير ARIA وتحذيرات اكتشاف الوكلاء والتحميل والكاش والصور وJavaScript.
هذه أرقام الفحص المرفق، وليست نتيجة تشغيل جديد بعد التعديل.

## الأسباب والإصلاحات

| البند | النتيجة في الكود |
|---|---|
| ARIA محظورة على حاويات عامة | أعطيت حاويات المعاينة ومجموعة اختيار الرأي دور group المناسب، بدل تسمية عنصر generic |
| مراجع تبويبات غير موجودة | جميع تبويبات المنتجات تشير إلى لوحة موجودة ذات معرّف ثابت، وتسميتها تتبع التبويب النشط |
| شجرة الوصول | فحص axe-core آلي للرئيسية يشمل الأدوار والسمات والأسماء والتداخل بين عناصر التفاعل؛ لا يغني عن اختبار متصفح Chrome الحي |
| llms.txt | الملف كان يُجاب عنه بـHTML وحالة 200؛ أضيف ملف Markdown حقيقي بعنوان H1 وروابط المحتوى الفعلي |
| ai-catalog.json | المسار كان يُجاب عنه بـHTML أيضًا؛ أضيف JSON صالح مع ard.json ورابط اكتشاف rel=ard |
| بيانات اكتشاف الوكلاء | الكتالوج فارغ لأن الموقع لا ينشر أدوات AI عامة؛ لم تُخترع خدمات أو صلاحيات لتجاوز الفحص |
| JavaScript غير المستخدم | فصل الرئيسية والخدمات والتواصل ومن نحن و404 إلى تحميل مسارات مستقل، وإزالة التضمين الثابت الذي كان يبطل lazy loading |
| سلاسل الاعتماد | تحميل مسبق لوحدات المسار الحالي واعتماداته من manifest في قالب Laravel، بدل انتظار اكتشافها تباعًا |
| CSS | نقل تنسيق بطاقات المدونة إلى ملفات مسارات المدونة، حتى لا يحتاجه أول تحميل للرئيسية |
| تأخر ظهور المحتوى | أول شاشة لا تبدأ مختفية بسبب GSAP؛ تحميل محرك الحركة عند خمول المتصفح، وتأجيل تهيئة deck حتى الاقتراب من عرضه |
| الصور | AVIF متجاوب لـ4 صور واجهات بمقاسي 480 و960، بأسماء مبنية على بصمة المحتوى، مع WebP احتياطي للمتصفحات الأخرى |
| الكاش | توسيع سياسة Apache لتشمل JPEG/PNG/GIF وAVIF، وكاش قصير لملفات الاكتشاف. الملفات ذات الأسماء المبصومة تحتفظ بكاش طويل |

## القياسات المحلية

- ملف JavaScript المدخل: 203,487 ← 84,983 بايت (حوالي 58% أقل قبل الضغط).
- ضغط gzip للمدخل محليًا: 57,979 ← 25,170 بايت.
- مجموع نسخ الصور الثماني: 579,136 ← 302,934 بايت؛ وفر 276,202 بايت.
- هذه مقارنات ملفات؛ ليست تقديرًا لدرجة PageSpeed أو لكل الزيارات أو لكل المسارات.
- تمت مقارنة صورة متجر AVIF مع WebP بصريًا للتأكد من بقاء النصوص والتكوين.

## التحقق

- نجح TypeScript/Vite و88 اختبارًا، ومنها اختبار axe-core واختبار منع إخفاء نص أول شاشة
  عندما يصل بعد تحميل كسول.
- نجح التحقق من ملفي الاكتشاف بمخطط ArdManifest المضمّن في Lighthouse 13.6.0.
- لم يتوفر PHP في البيئة لتشغيل قالب Laravel؛ يلزم اختباره بعد نشر الواجهة والقالب معًا.
- محاولة تشغيل PageSpeed عبر Google API أعادت HTTP 429. لذلك لا توجد درجة جديدة موثقة.

## الحدود وما يحتاج تحققًا بعد النشر

1. أعد الفحص بعد وصول ملفات build والصور وllms.txt ومجلد .well-known وقالب Blade إلى الاستضافة.
2. تحقق من أن ملفات الاكتشاف تُرجع text/plain وapplication/json، وليست صفحة HTML البديلة.
3. تحقق من استجابة الكاش على الاستضافة نفسها؛ إعدادات Nginx/CDN قد تتجاوز .htaccess.
4. ملف CSS الأساسي يبقى stylesheet ضروريًا للتصميم؛ لم يُحوّل إلى تحميل غير متزامن يسبب
   ظهورًا بلا تنسيق. لا يُدّعى اختفاء تشخيص render blocking بالكامل دون فحص حي.
5. تحسين DOM وتشخيص مهام الخيط الرئيسي ليسا عطلين مستقلين في الصور؛ تقليل الحزم وتأخير
   الحركة يعالجان مساهمتهما دون حذف المحتوى أو الحركات المعتمدة.
6. لم تُغيّر إعدادات لوحة التحكم أو CMS التي طُلب التراجع عنها.
